# DATA 201 Project 1: Bank Marketing
Project 1 for DATA 201 is currently in progress, in which four classification models (logistic regression, LDA, QDA, KNN) are used to predict whether a customer will subscribe to a term deposit, and the goal is to compare their performance and explain which model fits this application, considering missed opportunities and unnecessary customer contact.

The project repo will include the notebook, dataset, and main findings. The project uses bank marketing data and is implemented in Python.
